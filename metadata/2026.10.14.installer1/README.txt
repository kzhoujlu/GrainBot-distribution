GrainBot Windows 安装器

1. 将本 ZIP 完整解压到一个文件夹。
2. 双击 GrainBot Setup.exe，选择安装位置。
3. 首次使用选择 CPU（推荐），点击开始安装；等待依赖和应用下载完成。
4. 安装完成后启动 GrainBot Launcher，打开网站服务。

这是联网安装器，适用于 Windows x64，需 .NET Framework 4.8。
前后端默认安装已经发布的 2026.10.14.post4；维护核心内嵌0.2.7。
模型、数据按需下载，不包含在这个小安装包中。
GrainBot Setup.exe.config 必须与 EXE 放在一起，用于界面渲染设置。
安装器目前未配置 Windows 代码签名。CPU/CUDA依赖选项的实际验收范围见Release说明。
